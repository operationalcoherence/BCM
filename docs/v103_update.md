contested word, the unreached cause, the bridging thread. Nothing checked that
the three were different words. On his real workbook they were not, and it read:

> Start with the contested word "fire", then the unreached cause "tradition",

> Start with the contested word "fire", then the unreached cause "tradition".

three happen to pick the same word, the line names it once.

Found 2026-11-08 while screening the reading pages. Pre-existing; the check
never existed.
